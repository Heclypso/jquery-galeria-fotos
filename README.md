## Objetivo

O projeto foi desenvolvido com intuito de criar uma biblioteca de fotos interativa.

## Tecnologias Usadas

- **HTML**: criação do esqueleto do projeto;

- **CSS**: criação do código de estilo do projeto;

- **JQuery**: manipulação do DOM para criar a funcionalidade de adicionar imagens, animações;
  
## Técnicas e fundamentos desenvolvidos

- Desenvolvimento de páginas WEB;

## Passos de instalação

1 - Clone o repositório

2 - Digite npm install no terminal do Visual Studio Code

3 - Digite npm run start no terminal
